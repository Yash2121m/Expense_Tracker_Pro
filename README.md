# 💰 Expense Tracker

A modern **Offline-First Expense Management Application** built with **Flutter**, designed to help users track daily expenses, analyze spending habits, and manage finances efficiently.

## ✨ Features

### 📊 Dashboard

* View total expenses
* Recent transactions list
* Category-wise expense overview
* Average expense insights
* Top spending category

### 💸 Expense Management

* Add new expenses
* Edit existing expenses
* Delete expenses with swipe gesture
* Expense preview before saving
* Date selection support

### 🏷 Categories

* Food 🍔
* Transport 🚗
* Shopping 🛍️
* Bills 💡
* Entertainment 🎬

### 📈 Analytics

* Category-wise Pie Chart
* Monthly Spending Bar Chart
* Spending Insights Dashboard
* Total Expense Summary
* Average Expense Tracking
* Top Spending Category

### 📄 PDF Export

* Generate expense reports
* Export transaction history
* Offline report generation

### 📱 Modern UI

* Material 3 Design
* Responsive Layout
* Blue Finance Theme
* Clean Dashboard Design
* Interactive Charts

### ⚡ Offline First

* No internet connection required
* Local data persistence
* Fast performance
